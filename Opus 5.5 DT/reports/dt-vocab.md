# Vocabulary and grammar sequence (PLAN 3f)

Generated by `node qa/audit-vocab.mjs`. Full data: `dt-vocab.json` in this folder.

**How it was measured.** All right Dutch in a level's items (sentences with the right options filled in, word, look, listen, read and de/het items) is split into words. Names and places from `qa/allow-words.txt` are left out. Each word is reduced to a rough lemma: an irregular verb table (ben, is, was, geweest all count as zijn) and a light stemmer (honden, hondje count as hond). The stemmer is rough: it sometimes joins two words or splits one, so treat single counts as approximate and the patterns as real.

**Frequency list.** `qa/data/nl-freq-top5000.txt`: the top 5,000 word forms of [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) `content/2018/nl/nl_50k.txt`, counted from Dutch subtitles (OpenSubtitles 2018). Licence of the list: CC BY-SA 4.0. SUBTLEX-NL would be the academic choice, but its licence is not stated as open; this list is built the same way (subtitles) and is openly licensed. It is used here only to measure, never shipped.

### Rule ids that name the same rule

These pairs split one rule over two or more ids, so a per-rule count (the weakest-rule line in 3d, the learner model in phase 4) sees two half-rules. Merge them before phase 4.
